# Project file guide

This guide covers files added or changed during the diffusion project. Paths are relative to the project root. Braces group files with the same purpose.

## Documentation and code

| File | Purpose |
| --- | --- |
| `README.md` | Commands to run the demo, reproduce the experiments, and assemble the submission. |
| `README_Directory.md` | This file guide. |
| `AGENTS.md` | Existing project instructions updated with the diffusion choice, classifier-free guidance, course constraints, and verification steps. |
| `AGENT_LOG.md` | Template for your three independent checks of the agent’s work. |
| `DATA_CARD.md` | Describes data curation, counts at each stage, and the student audit. |
| `report.pdf` | Four-page report draft with methods, evaluation results, experiments, and references. |
| `.gitignore` | Existing ignore rules extended to cover local caches, checkpoints, and audit images. |
| `curate.py` | Scans the raw pool for cat and dog heads, filters candidate crops, builds the manifest, and renders review sheets. |
| `photo_filter.py` | Uses CLIP to check whether candidate crops and their source images are photos of the intended animal. |
| `configs/exclusions.csv` | Lists pool images removed during visual review and the reason for each removal. |
| `train.py` | Trains or resumes the diffusion model from manifest crops and exports the chosen checkpoint. |
| `compare.py` | Compares checkpoints and guidance scales using aggregate dev-set metrics. |
| `demo.py` | Generates a cat and dog sample grid from a seed and prints a pixel checksum for replay checks. |
| `deliver.py` | Checks the completed audit, calculates its uncertainty, rebuilds the data card and report, and packages the submission with your slides. |
| `tests/test_project.py` | Tests crop geometry, duplicate filtering, denoising, the generator interface, and seeded replay. |

## Model and audit

| File | Purpose |
| --- | --- |
| `submission/generate.py` | Replaces the starter placeholder with the denoiser, DDIM sampler, guidance, and official `load_model` and `generate` entry points. |
| `submission/manifest.csv` | Lists the 2,072 training crops by raw-pool ID, crop coordinates, rotation, and class. |
| `submission/weights.pt` | Exported model weights from step 36,000, configured for 32 DDIM steps and guidance scale 3.5. |
| `audit/audit.csv` | The course tool’s 200-crop sample with columns for your verdicts and reasons. |
| `audit/sheet_{00,01,02,03}.png` | The four official audit sheets. Each shows 50 indexed crops. |
| `work/audit-sources/sheet_{00,01,02,03}.png` | Companion sheets showing source images and crop boxes for the same audit indices. |
| `work/demo.png` | Sample grid generated by the selected model with seed 3024. |

## Experiment records in `results/`

| File | Purpose |
| --- | --- |
| `data.json` | Counts and settings from the final curation run, including model and manifest checksums. |
| `train_config.json` | Training settings, device, seed, and manifest checksum. |
| `loss.csv` | Mean training loss, learning rate, and elapsed training time by logged step. |
| `selection.json` | The chosen checkpoint and sampler settings, with the reason for selecting them. |
| `official.json` | Full official dev-set evaluation of the selected model, including metrics and hard-limit checks. |
| `official.png` | Generated sample grid from that evaluation. |
| `full-024000-cfg1.5.json` | Full dev-set evaluation of the earlier 24,000-step checkpoint at guidance scale 1.5. |
| `full-024000-cfg1.5.png` | Generated sample grid from that earlier evaluation. |
| `verification.json` | File checksums, official sample count, test count, and seed-replay results. |
| `trial-{step}-ddim32-cfg{scale}.json` | Metrics for a comparison run with 160 samples per class. |
| `trial-{step}-ddim32-cfg{scale}.png` | Generated sample grid for the matching comparison run. |

The trial pairs cover step `002000` at scale `1.5`, `012000` at `1.5`, `024000` at `1`, `1.5`, and `2.5`, and `036000` at `1.5`, `2.5`, and `3.5`.

## Downloaded assets and installed dependencies in `data/`

| Path | Purpose |
| --- | --- |
| `yolo26n.pt` | Pretrained YOLO26n weights for detecting cats and dogs in the raw pool. |
| `pet_head_yolo26n.pt` | Pretrained pet-head detector weights for locating crop boxes. |
| `ViT-B-32.pt` | Pretrained CLIP weights used by the photo filter. |
| `openai-clip-source.zip` | Downloaded archive of the pinned OpenAI CLIP source. |
| `CLIP-a1d071733d7111c9c014f024669f959182114e33/` | Extracted CLIP source. Its `clip/clip.py` has an import fix for Python 3.14. |
| `clip-deps/` | Project-local installation of CLIP’s `ftfy` and `regex` dependencies. |
| `ptrc-deps/` | Project-local installation of PyTorch, Ultralytics, OpenCV, and report dependencies. |

The supplied pool in `data/student/`, the dev set in `data/dev/`, `handouts/`, and `starter_kit/` predate this work. The root `eval_results.json` and `eval_results.png` are from the original starter-template evaluation. The trained model’s evaluation is in `results/official.json` and `results/official.png`.
